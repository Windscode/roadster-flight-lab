# 制动接触回归的 3.19 测试适配

## 原失败与根因

当时的运行构建 `8ccb2ab0d967509682aae900ba5a9067bd986d8468f5d5f57f48256fcb857579` 的全量回归 attempt-02 在 `tests/braking-footprint-3.16.test.mjs` 第一项失败。本文保留该阶段的真实身份；后续英文说明修复后的最终构建另见验收报告。旧断言要求当前 `_wheels` 函数体与冻结的 3.16 force-pass **逐字相同**。3.19 已增加轮胎滑移功率、接触开始反馈、表面元数据和接触法向查询，因此这个源码字符串条件不再成立。

失败不是初态不一致：六对原完整快照及其标签全部相等，路线表面描述均为 `null`。旧三站支撑查询仍在 0.025 秒内产生轮肩接触；100/200/300 km/h 的最大偏航绝对值分别约为 0.182544°、0.024131°、0.059659°，每个速度均有左右微扰两次。现行连续冠形查询的六次最大偏航约为 0.000573–0.000596°，全部停稳。其余六项原力学/几何断言当时均通过。

原失败报告与原轨迹逐字节保留于：

- `qa/development-3.19/braking-footprint-before-test-adaptation/braking-footprint-3.19.json`
- `qa/development-3.19/braking-footprint-before-test-adaptation/braking-footprint-3.19.ndjson.gz`

## 先验证物理路径，再适配断言

在修改测试之前，独立执行了原六个完整初态的同支撑对照：当前 `_wheels` 与未改动的冻结 force-pass 都使用现行连续冠形查询。共 3,322 个 120 Hz 步，每一步的完整导出状态精确相等，仅排除冻结函数没有写入的两项新只读轮诊断 `slipPowerW` 与 `contactNormalSpeedMps`。

比较仍包括完整刚体和世界状态、接触反馈、轮胎力、轮速、ABS、制动及驱动能量、燃气和电能状态。各轮 `_surfaceAt` 每一步均返回 `null`，实际附着系数均等于原 `tireMu`。这项结论只覆盖这六条原未映射干路制动轨迹，不推断所有新增路面或落地工况与旧版相同。

## 测试如何保持原要求

现有冻结支撑查询、冻结 force-pass 和 provenance 文件都未改动。适配只做两件事：

1. 对源码比较列出十项**精确匹配且各出现一次**的已审新增代码，把它们投影回原函数体。投影仅用于比较，不生成或执行替代物理代码；其余每个字符仍必须与冻结函数相同。原始函数体不相同的事实继续记录为 `identicalWheelForcePass: false`。
2. 把上述逐步精确状态对照纳入每次回归。任何原物理状态差异、非空路线描述或改变的实际附着系数都会令第一项断言失败。

原 100/200/300 km/h、左右微扰、0.01° 偏航阈值、停止条件、0.025 秒缺陷出现时限、四轮支撑、零刚体冲击、零接触细分、制动力/扭矩/附着预算及接触几何阈值全部保留。没有修改任何 runtime 文件或最终模型身份，也没有把原数值异常边界改为通过。

最终结果与源码哈希写入 `qa/braking-footprint-3.19.json`；报告包含完整源码投影清单、原函数/投影函数/冻结函数哈希以及六组逐步对照结果。数值测试不代表原生键盘、图像、声音或用户 GPU 验收。
