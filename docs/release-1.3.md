# Roadster Flight Lab 1.3

从正式版 1.2（`0d40843`）继续开发。这一版让驾驶者能在城市里找到刹车点，也能在实验室里量出不同路面的制动距离与能量去向。[进入城市](https://windscode.github.io/roadster-flight-lab/) · [制动与控制实验](https://windscode.github.io/roadster-flight-lab/?view=study)

## 地面与飞行

1.2 把轮胎滚动阻力乘上了踏板比例。关闭松油减速后，在 64.8 km/h 松开所有踏板滑行一秒，账上滚动损耗为零。1.3 根据各接地轮的法向载荷计算滚阻，沿用 0.011 的系数。相同测试得到 4.24 kJ 滚动损耗，末速 63.99 km/h，电池回充为零。刹车灯读取车轮实际制动和回收扭矩，单纯滚阻或风阻导致的减速不会触发回收制动灯。[滑行与能量数据](../qa/release-1.3/driving-study.json)

在城市外供气起点，用 H 进入辅助飞行并按 E 爬升。松开后仪表从 5.0 m/s 爬升指令转为 5.55 m 保持高度，再按 H 交还控制时指令立即归零，阀门余推随后消退。落地后按 X，界面记录了 3.94 s、360.9° 的动作，确认四轮承载后恢复驾驶者控制。数值检查另覆盖有限气源、上方净空、接触交接和组合输入。这些测试对应各自的气源、初态与环境。[着陆实景](../qa/browser-1.3/roll-landing.jpg) · [自动动作包线](../qa/maneuver-envelope-1.3.json) · [输入与着地交接](../qa/control-continuity-1.3/report.json)

## 车模、路口与街景

工坊之前给两只前轮同一转角。现在车轮、转向控制和工坊姿态导出共用驾驶中的转向几何。中心指令 0.49 rad 时左前轮 32.6°，右前轮 24.6°；反向转弯时两侧交换。可在剖视中观察内轮转角更大。项目的外形参考和隐藏机构假设见模型资料。[工坊实景](../qa/browser-1.3/ackermann-workshop.jpg) · [外观参考](../dist/assets/references/README.md)

织桥街的琥珀色路面箭头按当前任务的弯心和出口方向绘制，帮助驾驶者在第三道计时线后找准左转路口。交易所街区的 16 个橱窗改成高架桥墩、桥面剖段和换乘示意。沿用既有橱窗批次、材质和照明。全城仍为 955 个已分配的绘制批次，与 1.2 相比装配后三角形减少 2,496 个。[路口实景](../qa/browser-1.3/weave-turn.jpg) · [街景与绘制预算](../qa/showcase-lighting-1.3.json)

追车相机复用物理世界的静态空间索引，以附近物体作精确遮挡检查。城市中共有 2,367 个碰撞盒。城市和风场的 720 次距离对照中，381 次发生遮挡，候选最多 29 个，命中的物体、距离与相机位置均与完整遍历一致。这验证了查询范围和结果。不同 GPU 的湿夜帧率、长帧和阴影观感仍需分别实测。[相机对照](../qa/release-1.3/driving-study.json) · [阴影运动检查](../qa/shadow-motion-1.3/report.json)

## 同条件制动与路线记录

标准实验现在支持指定制动起始电量并切换回收。速度和轮速按同一初态准备，制动开始时记录实际车速，从能量账读取截至首次静止的电池回充、摩擦热和滚阻损失。持续停稳半秒后确认结果。载入旧方案时保留原有初态规则。

| 80% 初始电量，目标 80 km/h | 停车距离，回收关 / 开 | 回充，关 / 开 | 摩擦热，关 / 开 |
| --- | ---: | ---: | ---: |
| 干地 | 24.97 / 24.97 m | 0 / 6.73 Wh | 130.45 / 121.81 Wh |
| 湿地 | 42.23 / 42.23 m | 0 / 6.04 Wh | 124.70 / 116.96 Wh |
| 分离附着 | 30.76 / 30.76 m | 0 / 6.47 Wh | 128.66 / 120.37 Wh |

六次结果的实际制动入场速度为 79.34–79.35 km/h。回收接替了部分摩擦制动，在这些初态和满制动指令下，两种设置的停车距离一致。命令行可用 `npm run research -- --preset brake-regen` 重做干地配对，默认写入本地临时目录。[试验结果](../qa/release-1.3/driving-study.json)

重新运行了三种有限资源驾驶策略和一组雨后路线，并核验整程重放。最终构建的桌面键盘自由练习用时 97.7 s，完成四段，回充 12.53 Wh。导出的 11,721 步输入在浏览器内按原条件复算，结果显示复现一致。雨后夜间另一次练习中途结束，重载页面后仍能查到已经完成的三段。浏览器存储已满时，路线面板允许直接导出和重试；未能保存的成绩留在会话内。在空间已满的另一轮 59.5 s 完赛中，实际下载的摘要包含成绩和四段数据。实验面板也会按实际保存状态提示导出。首次加载时，材质与车辆准备好后驾驶入口才可交互；路线准备期间也会暂时锁定条件，以免误用上一轮起点。[路线数据与重放](../qa/resource-1.3) · [浏览器验收](../qa/browser-1.3/observations.json)

1.2 的 12,534 步键盘记录可在新模型下显式重算。原记录继续保留其历史构建身份。发布检查覆盖数值、输入、界面与重放；本轮浏览器验收使用 Windows 桌面内置浏览器，未测物理手柄、移动设备或扬声器听感。[当前检查](../qa/release-1.3/validation.json)
