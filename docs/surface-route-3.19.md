# 3.19 织桥街表面、驾驶与声音闭环

## 范围和继承

基于 3.18 物理/完整城市继续实施，保留原独立轮速、悬架、联合附着、ABS、TCS、安全转向、轮胎功核算及未解决的高速硬台阶边界。没有改变车体质量、惯量、轮心、喷口或接触限值。新增信息反馈读取实际解算状态，不向刚体施力。

路线沿已有街道：`(-200,-380) → (-200,-132.5) → (-145,-132.5)`，折线长度 302.5 m。从 +Z 行进后转向 +X，是驾驶者 **A 左转**；地图横轴取负 X，不用容易混淆的东西标签。数值驾驶在原交叉口自然转弯，实际轨迹约 297.44 m；它没有经过折线角点后瞬间改变方向。

3.18 已完成的浅橱窗、陈列、凹入口和上层帘幕保留。新中尺度资产/可见表面由城市模块记录，本文件说明共享条件与物理/声音。

## 一份可序列化表面描述

`dist/route-surface.js` 是唯一地图描述。两种预设为 `dry-day` 与 `after-rain`；均保留相同道路、金属检修板、修补面和区域几何。材质的 `moisture`、`opticalWetness`、`gripScale` 是三个独立字段，不从 shader 颜色或装饰水洼推断附着。纹理压纹不产生碰撞起伏。

每个轮胎用它自己的实际世界接触点和支撑法向选择区域，再进入既有轮胎解算器。`mu = tireMu × gripScale`；下表以默认 `tireMu = 1.25` 为例：

| 区域材质 | 干燥预设 mu | 雨后预设 mu | 雨后光学湿度 |
|---|---:|---:|---:|
| 基域干沥青 | 1.25 | 1.25 | 0 |
| 标定潮湿区 | 1.25 | 0.70 | 0.72 |
| 平齐检修钢板 | 0.90 | 0.525 | 0.48 |
| 平齐修补面 | 1.125 | 0.95 | 0.18 |

这些是少量、有界的工程假设，不是路面实测、原厂轮胎数据、水膜流体或水滑模型。光学湿度与附着独立使研究能够明确控制变量；不能把湿颜色简单等同于上述 mu。

地图含两个道路基域、六个覆盖区域，按显式 priority 与数组顺序选中；CPU 查询与视觉使用同一描述。支持高度是地面 Y=0，容差 0.08 m，并拒绝低于 0.85 的支撑法向 Y 分量。同 XZ 的 20 m 高架和 5.4 m 步廊不会误采下方湿区。

`routeSurfaceHash` 是对规范化完整描述计算的 `fnv1a32` 内容标签，明确不是密码学签名。验收报告另列 JSON 字节的 SHA256。完整描述保存在物理快照 `_routeSurface`，不是仅保存预设名字；新记录的条件身份与快照内容标签覆盖实际描述。

## 应用与历史规则

`sim.setRouteSurface(descriptor,{phase:'preparation'})` 必须是显式准备动作。暂停、是否存在活动记录/任务由主界面负责检查；普通运行中的观赏昼夜切换不调用这个方法。

`sim.getRouteSurface()` 返回 `{descriptor,descriptorHash}`。`telemetry.roadSurface.preset === 'route'` 表示当前启用接触地图；`params.roadSurface` 保留区域以外的旧 fallback，不能单凭它把整车条件标成全局干路。

原 `setRoadSurface('dry'|'wet'|'split')` 明确退出地图，继续使用原全局干/湿或世界 X 分界规则。没有地图的既有物理路径保持原数值行为。旧模型 exact replay 仍受模型身份检查；新增 snapshot 字段的缺失显式解释为无路线/无历史接地反馈，不继承当前现场的路线或声音事件。用户明确发起的已支持历史模型重算仍须保留其单独兼容声明。

## 声音来自什么

- 轮胎摩擦声读取 `wheel.slipPowerW`：当前轮胎纵向实际耗散功率，加上已解算横向摩擦力与横向速度的耗散功率。轮载决定支撑权重；速度/接触门控避免静止与离地胎噪。
- 滚动底噪沿用真实行驶速度和载荷，金属/修补面只改变有界音色纹理。ABS 纹理读取实际 `absActive`，没有以刹车按钮直接伪造 ABS。
- 接地声读取有明确离地窗后第一次重新承重时的法向入射速度。等效法向能量使用每轮四分之一车重的工程近似；记录的冲量仅为开始接触切片的实际弹簧支撑冲量，不假称整个着陆冲量。
- 车壳撞击读取已存在 Cannon 约束账本的首次接触能量损失/冲量。接触锁存使用当前 manifold，即使诊断账本达到有界长度也不在连续接触时重复触发。
- 同一次前后轮着陆按短窗合并为一个事件。音频门控按事件身份只调度一次包络；严重峰值没有转成损伤值。

声音均为合成反馈，不是 Tesla 实录或具有标定声压的工程声学。音频调节器的状态在音频对象中；物理反馈状态只记录观测，不参与力、资源或控制计算。

每轮遥测提供 `surfaceId / surfaceMaterial / surfaceLabel / surfaceMu / opticalWetness / slipPowerW / absActive / contactNormalSpeedMps`。`contactFeedback.lastEvent` 提供时间、物理步、参与轮、能量、冲量、正常入射速度和测量口径；它进入同一记录链。

## 实际数值结果与限度

可执行验收：`node qa/surface-route-3.19-check.mjs`。精确阶段 modelVersion/build 以同目录 `numerical-report.json` 与 `route-drive.json` 为准，产品冻结后应重新生成，不将早期报告回填为最终 build。

| 同初态、同输入案例 | 干燥 | 雨后局部湿区 |
|---|---:|---:|
| 60 km/h 全制动停止距离 | 15.432 m | 23.626 m |
| 同一制动停止时间 | 1.683 s | 2.692 s |
| 45 km/h、steer=0.75、throttle=0.02、1 s 后航向变化 | 26.509° | 15.874° |
| 上述转弯最终车轮中心转角 | 8.058° | 4.708° |

两条制动轨迹均真实触发 ABS，轮胎联合力没有超过自身 `mu × normalLoad`。转弯保留既有安全转向：同样的驾驶输入在低附着处被限到较小轮角。这是普通驾驶结果，不能称为固定轮角的轮胎辨识实验。

半幅边界实际出现同车两侧 mu=1.25 与 0.70；停车后胎噪归零；0.82 m 与 1.6 m 高度的自然落下分别观察到约 2.12 kJ 与 18.70 kJ 的接地法向能量，每次均只调度一次事件，之后保持四轮接地数秒没有重复爆响。

完整路线有两次实际全城物理积分：驾驶反馈策略只输出油门/刹车/转向，初始准备后没有改车体位姿。两次均经过所有四类材质、完成左转、到达终点并停车，全程最少四轮支撑、刚体撞击步数为零、喷气为零。干/雨后实际距离约 297.44 m，含停车阶段用时约 45.48 / 44.95 s。这里采用同一数值驾驶策略，但它随车辆状态生成不同输入，**不能解释为严格控制器 A/B，也不是原生键盘驾驶录像**。

读取全部声音反馈与关闭反馈的两辆同初态车，在 360 个固定步上的车体/气量/电量/轮状态完全一致，末态完整快照也一致。以独立保留的 3.18 物理模块作对照，无表面地图的 1200 步连续油门/转弯/刹车结果逐步一致。

这些数值结果不能替代可见材质验收、声音设备听感、驾驶舱舒适性、原生按键闭环或用户 GPU 帧时。高刷新率阴影、严重高速台阶和手动 E+1 的既有边界保留在总报告。
