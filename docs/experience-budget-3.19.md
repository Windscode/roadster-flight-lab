# 3.19 体验与渲染预算：实施前登记

基线：3.18 `eb2ca9d67f5b9fe7a81907f5304646e585a535e6`。本轮在完整城市内使用现有 302.5 m 折线路线，不改地图范围、建筑数量与道路碰撞几何。

## 不随验收结果上调的结构预算

- 保留现有十五视点的逐视点 draw-call 上限与既有三角形上限；仍运行原 `qa/exterior-materials-check.mjs`、`qa/render-budget-check.mjs`。
- 保留三档阴影分辨率、级联、反射尺寸与更新机制；不关闭阴影、不移除建筑来达标。
- 代表视点 balanced 保持既有 <300 calls、<650k triangles 门槛；完整环境已有 <400 calls 门槛继续有效。各自测量范围不混为整机 GPU 性能。
- 新表面描述绑定既有道路材质：新增纹理 0，新增道路 draw 0，固定容量分区 uniform。模块接合件复用现有材质批次，新增近街几何预算 ≤12k triangles。

## 用户 GPU 实机目标（尚未测得）

参考用户已说明的 RTX 4080 Super；显示器的实际像素尺寸尚未核实。登记测试条件为 3440×1440、balanced、渲染倍率 100%、同曝光日间/夜间，5 s 预热后连续完整路线。若用户实际分辨率不同，单列条件，不移用门槛。

目标：显示帧时 p50 ≤16.7 ms、p95 ≤25 ms、p99 ≤50 ms；专用显存总占用 ≤8 GiB，新增内容相对同条件3.18峰值增量 ≤128 MiB。以上为预登记目标，不是性能承诺或已测通过值。浏览器无显存接口时需外部设备计量；Three 的资源计数不能称为字节显存。

云端 Disabled / SwiftShader 或软件渲染均不能代替该硬件验收。相机固定暂停帧不能代替连续驾驶帧时。

## 两个体验闭环

1. 同初态的干/雨后路面准备 → 显式记录 → 连续驾驶/制动/转弯/跨界 → 四轮接触材质与滑移声音 → 路线结束记录。湿度、光学湿润和附着分别定义；观赏光照切换不得修改物理表面。
2. 首条违规及前序事件 → 对应记录失败前三秒的暂停复盘 → 相同完整初态的新练习 → 按事件比较不同人手输入。原模型不可用时只读旧数据，正式排名不含练习。

驾驶员头部反馈只在驾驶舱平移眼点，最大侧向25 mm、垂向12 mm、纵向35 mm，无额外滚转。开关不改变刚体、输入、控制器与固定研究相机。
