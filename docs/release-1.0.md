# Roadster Flight Lab 1.0

1.0 是首次正式产品版本。3.19–3.24 是此前开发迭代编号；本次从 3.24 `6d55c5f` 继续，完整保留较新的本地成果及历史证据。线上版本以网站根目录 `deployment.json` 的提交和构建身份为准。

## 本次改变

**操控和物理边界。** 保留 120 Hz 求解器、真实执行器限制、资源账本及 X 的 1.5 秒翻转参考。默认条件仍使用分阶段净空预估；有限气源、自定义参数、风、观测扰动等超出已验证范围时，改用明确标注的开放上方通道筛查，修复低重力条件下旧回退估计漏检屋顶的已知反例。此筛查会保守拒绝自动动作，仍允许手动研究；它不是轨迹上界证明或连续碰撞保证。没有增加推力、抓地力或强制姿态来掩盖问题。

**车身。** 前翼子板包角从直线倒角改为连续椭圆曲面，上盖和碳色下沿共用边界，改善侧面到车头的体量过渡。与前轮拱、轮位、悬架和既有尾部曲面衔接，三个画质档的网格和绘制批次数不增加。该曲面是独立造型假设，不是新获得的原厂尺寸或工程 CAD。

**城市和渲染。** 保留完整城市、所有道路和分区、210 个首层展示柜及既有材质。夜间每档画质保持固定的路灯/车灯着色器槽位，空位发光为零，避免沿途光源数量变化触发整城材质变体编译。昼夜切换复用相同配置的级联阴影；质量变化、反射探针和延迟加载材质在明确的准备阶段完成，期间车辆不前进，准备完成从原位置继续。修复准备阶段可能污染上一帧性能统计的问题。预热和准备时间单列，实际驾驶长帧仍保留。

**实验连续性。** 成绩比较改为核验完整物理初态；只有通过场景兼容验证后，才允许忽略跨 JavaScript 引擎的原始几何哈希差异。不同参数、噪声种子、控制器状态或实际几何仍不能混成公平对照。3.24 记录可明确选择“按当前构建重算”，只迁移版本字段，不补造状态；原文件、来源身份和输入保持不变。这不是跨版本精确复现。更早记录仍可查看和导出，不能通过这一专用迁移路径重放。

**上手和发布。** 首页直接提供路线与挑战入口，以及折叠的三个驾驶要点。帮助、升降说明和可访问标签随实际改键及语言同步。风场、自定义控制律、着陆 A/B、资源路线和复盘继续使用相同物理和记录能力。发布流水线先通过物理、输入、研究、界面和静态发布检查，再部署已提交字节；测试依赖不进入公开站点。

真实浏览器验收还发现并修复了快速连续切换画质/昼夜时的材质释放竞态：准备期间只保留状态提示，其他交互暂时锁定，不能释放编译器仍在读取的材质；完成后恢复控件原状态。专门的待决编译回归检查确认场景、天气、快捷键和完整物理初态不受影响。被否决候选的画面、性能及失败原因保留在 `qa/browser-1.0/candidate-75482126/`，不冒充最终构建验收。

## 最终构建的实机验收

59 项发布检查全部通过，包含 28 组同页界面集成检查。最终构建 `e0aebd1ac7fa158e1abed3f0c8a7d24abc5243f43125d37e0ebeeeb82328326c` 在真实 Chromium/WebGL 中分别完成白天、湿夜的 180 秒城市环线重放，全部 3,601 个存储采样核验通过。路线约 1.57 km，使用普通方向/油门命令经过完整物理求解，行驶中没有直接设置车辆位置。

RTX 4080 SUPER、1280×720、高画质，各预热 5 秒后采集 150 秒活动驾驶：白天帧耗时中位数 7.5 ms、P95 7.9 ms，湿夜中位数 7.5 ms、P95 15.1 ms。白天仍有 4 帧超过 50 ms（最大 359.7 ms），湿夜有 3 帧超过 50 ms（最大 637.6 ms）。这些帧完整保留；原因尚未被完全定位，不能宣称卡顿已经消除。此前切换配置可能预热了驱动缓存，因此不是冷启动或前后性能对比。

首次图形配置准备可能需要数十秒，车辆在准备期间暂停；最终版本已验证准备完成后可继续操作。3.24 记录的显式重算也在真实页面完成；大记录达到本地存储上限时，页面提示仅在当前会话保存并允许导出，保留原有归档。验收原始文件均附身份和哈希，历史数据未改写。

历史缺失归档不伪造；3.24 及更早 QA 保持原身份。完整销毁/城市热重载、更多实测标定、有限气源自动动作扩展可行域和进一步城市美术深化属于后续工作，1.0 不是工业级模拟器或商业 3A 体量。
