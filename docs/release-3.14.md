## 首先解决的渲染/导出问题

3.13 用户实机高→流畅→高已经提供可见恢复和具名 clean draw，不能重新称为“高档缺绘未改善”。极高 08 仍有 25 个程序的 GL1286，尽管链接/验证成功且道路14、矿物13未超16；旧诊断的 `offscreen:256xundefined` 只是定位线索。

本轮独立复现仓库 Three 的 cube target 单参数 `setSize` 把 height/viewport 变成 undefined，修为尺寸改变时完整重建与同尺寸复用。新增真正已绑定 FBO 完整性和附件查询、pass/target/draw 关联；修复无 program attempted draw 吞错误的额外诊断漏洞。未把 CPU 构造错误说成已经在目标驱动证明的唯一根因。

14 帧矩阵现在区分 collection 与 draw 状态，20 秒无帧/编码超时、ESC、晚回调和 ZIP 失败都明确收尾；失败也保留前缀，0/14 不伪造 PNG。“重新下载最近采集包”保留本会话成果。详细根因、前后夹具和最少设备补采见 [渲染报告](rendering-3.14.md)。

## 配平反例、接触与快翻的准确结论

旧 `_holdTrimFeasible` 只验证均分候选，会把存在可行解的状态判为不可行。水平高压、FL 失效时，新测试质量 2199.5582 kg、重力约 21577.6659 N；FR/RL 各 **10788.8330 N**、其余 0 即可抵消重力和滚转/俯仰力矩，低于每个 20 kN 上限。独立 Python 用喷口位置×方向重建 wrench，再用 HiGHS 验 4 只口×4 档健康度×3 压力×5 姿态的 240 个条件。

该反例仍没有双向滚转/俯仰余量，**静态可行不代表扰动后能恢复**。界面公开合力/力矩残差、静态候选、饱和及单轴剩余能力；不直接设置姿态或速度。具体容差与限制见 [物理操控报告](physics-controls-3.14.md)。

接触矩阵保留 2/5/10 cm 台阶、单轮台阶、坡顶/坡底、桥墩正碰/斜擦、护栏、硬着陆与键盘/模拟量转向。旧 20 km/h 前置条件因再生制动降至约8.78 km/h的失败保留，随后用明确关闭 regen 的被动夹具隔离接触，生产值没改。90 km/h 撞 10 cm 台阶仍可失稳、车壳触地并显著损速；它不是“合理行驶通过”，也未被归为 solver fault 或靠锁姿态消除。

X 保留 quick-roll-1，未重新绑定舒适手动包络。当前同初态 ground / bench 600 L 的数值 metrics 与 3.13 逐值一致：最高 CG3.904829594 m、滚转累计峰365.785030°、内部退出3.691667 s、到该终点外供气吞吐150.179731 kg。用户独立真人记录是 CG0.597009→3.904830 m、roll峰365.510947°、+3.516667 s首次两轮接触；两组统计不混用。**本轮没有声称精确360°、精确原地落稳，或有限储气所有初态均通过。**

Tesla 官方 `@tesla` 的 [The Kickflip | Roadster](https://www.youtube.com/watch?v=r5vsHHPVhJg) 来源/演示身份已经确认，3.13 文档已纠正。视频仍未提供经过标定的质量、供压、准确高度/时长和完整遥测；作为动作观感参考，不反推成已验证实车参数。

## 新研究入口怎么用

进入 [风场实验室](https://windscode.github.io/roadster-flight-lab/?view=lab)，研究控制台选 **控制律 / 着陆**。先检查常驻任务初态、目标高度、场地界限、气源、时序、故障和成功条件。

1. 用 PD 模板运行默认任务；三维不可用时界面仍可明确选择后台数值运行。
2. 在 AST 编辑区改变比例/积分/滤波/限幅的组合，保存为自己的算法，再选 **同任务重执行**。它重新决策实际输出，与旧“固定输入 A/B”分别保留。
3. 并排比较先看模型、完整初态、风、气源、碰撞、任务和算法差异。不受控的两条记录只显示描述性比较。
4. 试有限100 bar失败、取消或接管；在时间线上定位风/故障/饱和/接触，再导出、刷新并重载。未保存提示独立持续显示，不能由“完成”覆盖。

高度外环 V1 只读必要观测，最多4状态槽/80节点/深14/12KB/96逐次运算，控制频率为120 Hz的整数分频；输出±6m/s²、变化率30m/s³，送入原控制/分配/阀门/气源。没有任意JS、eval、网络、文件、DOM或无界循环。异常/预算/退出保留精确步骤并撤销控制，Worker不是唯一安全边界。[实现、持久化夹具与边界](research-platform-3.14.md)。
