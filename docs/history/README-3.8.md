# Roadster Flight Lab · 3.8 可重放研究、轮速动力学与织桥湿夜

基于 Tesla 新 Roadster 官方公开照片与功能说明的独立六自由度仿真。车轮驱动、压差吸附、冷气推进与自动控制作用于同一个动态刚体；车辆外观、城市与界面为独立重建。这不是原厂 CAD、实车标定数字孪生或原生 3A 游戏成品。

## 启动与游玩

在线打开：**[三维试验场](https://windscode.github.io/roadster-flight-lab/)** · **[风场实验室](https://windscode.github.io/roadster-flight-lab/?view=lab)**。公开源码：[Windscode/roadster-flight-lab](https://github.com/Windscode/roadster-flight-lab)。三维驾驶需浏览器支持 WebGL 2 并开启硬件加速；图形不可用或上下文丢失时，同一页面仍可查看、导出历史并运行标准数值实验。首次进入三维需要载入城市纹理与模型。研究计算、实验库和本地音乐仍在访问者自己的浏览器内运行。

Windows 双击 **启动试验场.cmd**，或执行 `npm start`，打开 http://127.0.0.1:8080/ 。Node.js 22+；全部运行依赖已本地保存，无需构建、联网或安装依赖。保留服务窗口；Ctrl+C 或 **停止试验场.cmd** 停止。修改 `dist/` 后刷新即可。

默认以流畅画质、外部持续供气进入暂停菜单。首页首先显示放大的“进入城市”，开始下城街市驾驶；“进入风场实验室”是同页的次要入口；城市和实验室分别保留车辆状态，可直接往返。ESC 返回菜单，实验、遥测、画质、车辆与参数位于菜单内。画质选择保存在本机；物理始终使用120Hz固定步长。车辆工坊是独立检查入口。

| 操作 | 按键 |
|---|---|
| 前进；行进中反向键先制动，停稳后保持约 0.28 s 倒车 | W / S |
| 地面转向；辅助飞行偏航 | A / D |
| 车轮机械制动（优先于电驱和地面后喷口） | Space |
| 后部冷气推进 | Shift |

| 平滑抬头 / 低头；关闭自动回正时松键稳住新姿态 | 1 / 2（小键盘和手柄 LB / RB 亦可） |
| 自动回正关闭时连续滚转；开启时辅助横移 | Z / B |
| 自动回正开 / 关；定姿定点在研究控制台设置 | G |
| 吸附开关 | F |
| 自动滚转并返回起始状态 / 自动着陆 | X / L |
| 保存的自定义姿态、风场或自动流程 | 3–9（小键盘亦可） |
| 菜单 / 暂停；继续 | ESC；P |
| 重置当前场景 / 人为补气 | R / T |

| 力矢量 / 城市地图或实验室控制台 / 纯净视景 | V / M / F9 |

1 / 2 使用受限俯仰角速度参考，交给姿态、位置反馈和非负推力分配器执行；键盘不再绕过配平直接打开前后轮对。默认外部持续供气，工程面板与研究控制台可切换有限储气。T 是显式的试验补气干预。

G 只开关自动回正。关闭回正后，H 辅助飞行仍有物理闭环：Z / B 连续滚转，1 / 2 改变俯仰；松键后捕获实际达到的姿态，通过真实喷力和力矩制动。WASD、E / Q 的移动输入仍优先。任意姿态都能静止并不是此喷口布局的能力；大倾角、倒置或推力不足会显示受限并真实漂移或下降。

X 记录启动时的地面/空中状态与世界高度，先建立转动所需的上升速度，再完成完整滚转并制动恢复。地面起始最终着陆、关闭阀门；空中起始回到原高度附近。预检检查实际上方净空和有限储气冲量，不把余量不足的空中动作偷偷改成降落。

## 3.8 当前版本

基于 3.7.0 的 `2411ede79f7d7d7501017dbb7f5346a50de2714a`，保留既有城市、同页风场实验室和流程快捷键。本轮实际变更及验收范围见 [3.8-UPDATE-NOTES.md](./3.8-UPDATE-NOTES.md)。

- **一次现场驾驶就是可重放实验**：记录完整物理续算状态、风相位、观测延迟缓存与种子、固定 120 Hz 输入、命令和人工接管／故障事件；支持原条件三维重放、返回重放前状态、无图形数值复算，以及同快照控制器 A/B。历史查看与当前构建重算分开；没有旧模型执行器时明确拒绝原条件执行。
- **独立轮速与真正的 ABS/TCS**：每轮角速度与惯量、驱动／制动／接地反力矩共同积分，具有低速正则化滑移和联合附着约束。道路可选干、湿、左右分离附着；高级研究新增起步协议和 ABS/TCS 配对，保留原标准实验身份。
- **尾翼是物理执行器**：展开量和速度限制、气动阻力／下压力、移动作用点进入物理状态，车辆网格读取同一执行器。提供固定收起翼／主动翼对照；气动系数仍属工程假设。
- **车模和一个完整街区**：修正座舱、肩线与车尾曲面、灯具和表面尺度；检视页支持同一 50 mm 机位下切换 3.7 外观基线与当前车模。保留全城，选定 1135 m 织桥—南岸环线并集中强化织桥主街，加入晴天与湿夜、真实有界近灯及受预算限制的湿路反射。
- **可核验的显示性能记录**：5 s 活动预热与 30／150 s 稳态采样分开，导出 rAF p50/p95/p99、长帧、CPU、可用时的真实 GPU 查询、设备和分辨率、位置轨迹与配置变化。此环境没有实际浏览器 GPU 验收；不能据离线结果宣称达到某个 FPS 或 3A 观感。

快捷体验：城市菜单的“记录这次驾驶／飞行”→操控→结束；打开研究控制台的“现场记录”查看和重放。标准实验位于同页“对照与扫描”；画质菜单内选择“织桥环线入口”、天气与固定机位。[车辆曲面检视](https://windscode.github.io/roadster-flight-lab/vehicle-inspection.html) 保留为专门的近景检查入口。

现场整库 JSON 包含现场记录及其关联的数值重放／A/B；标准实验整库 JSON 包含标准报告和执行尝试；流程 JSON 是操作配方。CSV 均只导出当前选中记录，保留该记录的身份、真实已存采样间隔和原始统计来源。旧曲线不会因为被打开就变成新版实验。

## 3.7 历史版本：驾驶控制与风场实验室

本轮修复转向、E/Q、X、G、Z/B 和 1/2 的相互作用，并将研究工作台接入同一个三维风场实验室。完整说明见 [3.7-UPDATE-NOTES.md](./3.7-UPDATE-NOTES.md)。

- 中速转向使用速度曲率与轮胎侧偏补偿，保留轮胎摩擦圆、转向执行器和高速限舵。
- 持续 Q 在承载轮胎接地后完成降落；阀门按原有关闭时间衰减，不再保持悬停推力。E 的正常升空控制不再被吸附开关绕过。
- 实验室具有共享视觉/碰撞几何、风机墙、测量网格、解析风示踪和目标姿态轮廓。城市不在后台继续积分；返回城市保留离开时的物理状态。
- 同页控制台支持自定义姿态/位置、九项控制参数、平均风与正弦阵风、流程编辑、3–9 快捷键、版本化 JSON、20 Hz 实测曲线与结果对比。
- 原参数扫描、A/B 对照、历史记录和协议重算迁移到同页高级研究面板；标准对照仍使用独立初态，保持可复现。
- 物理和自动流程按固定 120 Hz 执行；20 Hz 测量由物理采样回调产生，与画面刷新率无关。实验室使用单主灯阴影和一次室内环境捕获，不计算城市局部反射或屏幕接触遮蔽。

数值/几何与静态集成结果见 `dist/validation.json`，本轮控制证据见 `qa/flight-controls-3.7.json` 和 `qa/flight-programs-3.7.json`。DOM 交互与离线着色器检查单独列出；它们不代表浏览器 GPU 帧率、画面验收或 Tesla 实车标定。

## 3.5 控制与性能更新记录

这次更新基于GitHub的3.4提交 `4a5cae1`，保留现有城市、独立研究工作台、音乐、碰撞与科学实验协议。详细修改和验证见 [3.5-UPDATE-NOTES.md](./3.5-UPDATE-NOTES.md)。

- **持续供气为默认**：`new RoadsterSim()`和“恢复默认参数”使用`bench`，每步仍记录实际kg/s和累计喷流冲量。既有有限储气科学协议显式保留`finite`，没有扩大气罐或掩盖放空。
- **修复真正的分辨率错误**：原`EffectComposer`保留启动时DPR，切换“流畅”仅改变主画布。现在主画布与全部活动后处理使用一致的实际像素尺寸，并限制超宽屏总渲染像素。流畅档有缓慢、有上下界的60FPS目标动态分辨率。
- **物理主线程优化**：把每子步清空约193万项的密集碰撞历史换成Cannon原生稀疏记录，并缓存非静态刚体查询列表。750个固定步整份遥测与接触方程严格等价；不降低120Hz频率或接触精度，相对CPU结果见`qa/physics-cpu-3.5.json`。
- **城市按距离和重要性提交**：建筑大体量保留，窗框/栏杆/店面微细节、街物、居民与植被分档裁剪。降低重复电缆、停用日间未使用的点光、聚光阴影和积水反射对象。流畅使用顶点计算的静态SH间接光，高档保留逐像素采样。
- **光影成本可控**：流畅一个1024阴影级联和静态环境反射；高档两个1536级联与128局部探针；极高三个2048级联与256局部探针。动态探针按六帧分摊，每帧最多一面；不再一次提交六遍城市。接触AO只计算深度/法线、遮蔽和滤波，去掉无用预览输出。
- **车身曲面和真实渲染LOD**：按官方当前照片重建连续玻璃、漆面高光、灯组与轮部细节；极高精度用于主要可见曲面。流畅真正降低网格细分、合并和隐藏细小内部结构；车轮与密封裙仍跟随物理。GLB导出和车辆工坊使用极高车模。
- **可检查本机性能**：驾驶画面显示实际帧率和分辨率；画质面板显示帧耗时、绘制调用、三角形数、CPU分项及可用时的异步GPU计时，支持30秒驾驶报告导出。未用Node几何数量推算或伪造实机FPS。

## 3.4 历史更新：实验、协议与城市规划

打开 `http://127.0.0.1:8080/research.html` 使用独立研究工作区；3.5将城市入口恢复为首页主位。三维试验场继续位于 `/`。两个工作区共享动力学源码，不把当前城市中的车辆位置悄悄带入定量实验。

- **六种固定协议**：转向阶跃、直线制动、空中稳姿恢复、普通E升降释放、悬停放空、弹道滚转。固定120Hz积分，20Hz原始样本；全部初态、完整参数、输入时序、强制覆盖、终态、事件与指标定义随报告保存。
- **单次 / 配对 / 扫描**：一次改变一个因子，3/5/7点等间距扫描；多曲线叠加、主指标比较、相对首条的数值差值、指针读数、本机最近12次实验库。导出JSON研究包及CSV；导入只恢复已验证的方案，忽略文件内旧指标，按当前协议重新计算。没有用无依据的参数分布伪造统计置信区间。
- **修正研究fixture与指标**：悬停初态同步水平位置目标，修复旧试验10s追赶185m的错误；道路侧偏仅在前进/接地/水平姿态有效时计算，空中滚转显示不适用。定速转向由普通油门/制动PI驾驶器维持并记录速度RMSE/饱和。有限供气把额定能力不足、持续高度误差超限、触地分开；恒压同时记录实际外供气量。滚转分别要求累计完整旋转、接触前120Hz样本垂速和连续0.5s稳定着陆。
- **源码身份与重算**：每份报告有模型版本、协议版本、完整源码SHA清单和构建SHA；请求身份也包含构建SHA。相同构建/协议/执行环境可逐样本复现。跨JavaScript引擎应比较合理浮点容差；几何本轮跨Node/Chromium量化到1e-9后一致，不能承诺所有平台逐位一致。
- **三个有身份的街区**：织桥街（弧顶交换厅、双层步廊）、机造里（9栋厂房、锯齿屋面、服务桥）、上城议庭（8m台地、林荫大道、半环柱廊）。114栋建筑；清理占地重叠、高架穿入公共前庭与楼梯净空。`M`打开规划图，标记节点后显示距离，`F9`隐藏仪表。地图、街区、主次街、步道、节点与实体来自共用规划数据。不是夜之城的资产复刻或AAA画质宣称。
- **音乐10首**：新增帕赫贝尔《卡农》、萨蒂《Gymnopédie No.1》、巴赫《BWV846前奏曲》的明确开放录音，以及两首独立流行演唱。古典/流行/氛围/本地分类、按实测整曲响度补偿，默认暂停/18%音量，J播放暂停/K下一首。曲谱与录音许可分别核实；原始作者/CC BY4.0或CC0/改编码说明保留。未打包未经授权的商业热门唱片，本地导入不会进入仓库。

### 一个可重算的研究例子

首页选择“摩擦系数如何改变制动距离”，直接运行三点扫描。80km/h初速、μ=0.65/0.95/1.25时，本模型制动距离约37.59/25.84/19.69m。距离从制动指令时刻开始，停止阈值0.1m/s并持续确认0.5s；这些数值不是Tesla实测刹停数据。

不启动浏览器也能运行同一方案：

```text
npm run model:build
node scripts/run-study.mjs --preset brake --out qa/my-friction-study.json
node scripts/run-study.mjs --preset attitude --out qa/my-control-study.json
node scripts/run-study.mjs --preset hover --out qa/my-gas-study.json
node scripts/run-study.mjs --plan qa/my-friction-study.json --out qa/my-friction-repeat.json
```

## 车辆、接触与吸附

模型对照Tesla官方12张多视角图，继续重做侧身曲率、座舱玻璃、灯窝、前后包围、轮毂与可见内饰。封闭车底顶板、轮舱/喷口隔离、外围柔性裙边和后方抽气通道用于说明压差机制；完整原厂底盘CAD、密封剖面与风机曲线没有公开核实，因此具体结构与尺寸属于工程重建。细节与轮胎净空检查见 `VEHICLE-MODEL-NOTES.md`。

四轮可视位置直接跟随物理悬架，长度范围0.24–0.41 m，配渐进缓冲及满压缩机械止挡。几何检查覆盖1774080个轮胎表面采样和±0.49 rad前轮转向；通过结论限于该刚性胎形和行程。

吸附不是任意空间引力。20段连续裙边从同一周界逐段探测附近表面，最长延伸0.44 m，渲染随各段真实间隙变形并补偿一帧插值。漏气流量满足 `Q = Σ(Cd × 段长 × 间隙) √(2Δp/ρ)`；压差受 `Δp Q ≤ 0.75 × 26 kW` 与8200 Pa上限共同约束。压差作用于4.8 m²有效面积，风扇有0.14 s响应；间隙变大即失去倒悬能力。它不是完整CFD或弹性接触求解。

## 制动与控制模型

120 Hz固定物理步长；角动量中点积分补全陀螺惯性；四轮弹簧阻尼、侧偏近似与合成摩擦圆。机械制动力上限42 kN，按当前轮载占比分配 `Bᵢ = B × Nᵢ / ΣN`，并受各轮合成摩擦圆限制；松油门仅有2.6 kN / 60 kW简化回收减速，不能等同踩刹车。修正了同时加速/后喷气时仍与刹车对抗的问题，反向键会先刹车。

模型平路计算：默认满气约2199.6 kg、μ1.25、无吸附、水平地面：100→0 km/h约31.0 m，50→0约7.8 m；同时按W+Space也能停稳。μ0.85时约45.4 m，不能通过无限提高摩擦系数伪造短制动。复现实验：`node scripts/measure-braking.mjs --output=braking-3.1.json`，详见 `qa/braking-3.1.json` 和 `qa/braking-comparison.json`。此前四轮等分制动力，后轮因制动减载先耗尽侧向能力，微小扰动可放大为甩尾。隔离碰撞、200 km/h、初始偏航1e-5 rad时，最大偏航45.21°→0.00067°；300 km/h为162.52°→0.00073°。见qa/handling-comparison.json，可用`node scripts/audit-handling.mjs --current --output=handling-after.json`复现。该EBD为理想载荷分配近似，没有独立轮速、液压ABS、实车轮胎曲线或路面水膜模型。

10个非负有界喷口通过真实位置的 `r×F` 提供力矩；高度PID、位置/速度反馈、四元数PD、滚转速度/加速度前馈为本项目控制器。阀门45/25 ms响应，绝热储气放空与换热，压力降低限制推力。世界空间白色凝结雾具有惯性、扩散和表面铺展，仅为视觉近似，不是CFD。官方静态喷流照片已查看；受登录验证阻挡的官方视频没有逐帧复核。

所有质量、惯量、喷口能力与控制参数均是研究假设。默认600 L、350 bar、293.15 K与等熵定效率喷管不能当作Tesla实车性能；650m/s仅保留作旧模型对照。完整公式/API见 `dist/physics-notes.md`。原版审查历史见 `AUDIT-AND-CHANGES.md`，备份位于 `.audit-backups/`。
