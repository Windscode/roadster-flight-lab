## 2. 转向打滑：已定位的因果修正

轮地基础并非缺少侧向力。独立检查的射线法向、接触点速度 `v + ω × r`、轮胎力方向和施力臂一致；平地法向合计 21577.597 N，与重力 21577.666 N 接近，质量/惯量保持一致。

真正有解释力的单项对照是：**松油再生制动均分压垮内侧轻载轮**，只改载荷分配便把对应峰值 β 从 34.17° 降到 2.79°；**湿路转向包络仍按干地抓地计算**，只改实际路面 μ 的输入便把对应峰值 β 从 12.86° 降到 2.12°；**全油转向的联合抓地余量不足**，主动减少共同驱动扭矩后对应 β 从 57.25° 降到 4.24°。这些分别位于 `dist/physics.js`、`dist/tire-dynamics.js` 和 `dist/vehicle-models.js`。

用户指出的 3 m/s 不连续也已复现并连续化：相邻采样力差从 1114.15 N 降为 1.11 N。但只做这项修复没有解决上述高速松油异常，未把局部线索机械提升为唯一根因。

### 最终同条件数值结果

统一协议为 **1 s 稳速准备 + 4 s 操纵计量 + 1 s 收尾**；下表记录 4 s 区间的峰值与实际起止速度。前版本为保留的 3.10 求解器源，后版本为当前 3.11；不是用户旧截图之间的对比。

| 工况 | 峰值车身 β：前 → 后 | 实际车速：前版本 / 后版本 |
|---|---:|---|
| 干地 90 km/h 起始，松油、完整映射转向 | 34.168° → **2.784°** | 89.89 → 33.01 / **89.89 → 62.39 km/h** |
| 湿地 90 km/h 起始，固定 2% 轻油、完整映射转向 | 12.860° → **1.955°** | 89.92 → 74.32 / **89.92 → 85.63 km/h** |
| 干地 54 km/h 起始，全油、完整映射转向 | 57.253° → **4.288°** | 54.24 → 112.13 / **54.14 → 84.65 km/h** |
| 干地 54 km/h 稳速，20% 输入 | 0.1152° → **0.1156°** | 两版均约 54.0 km/h |
| 干地 90 km/h 稳速，20% 输入 | 0.4855° → **0.4757°** | 两版均约 89.9 km/h |

全油工况在全部 4 s 内都主动限矩，最小驱动比例约 0.145；速度上升较少是实质取舍。20% 稳速输入在旧版原本没有严重滑移，不能把基本不变的结果夸成全工况改善。也不能只看 β：关闭 TCS 的补充样本车身 β 较小，但轮胎纵向滑移达到 0.761、抓地预算接近全程饱和。

[完整车辆与飞行报告](vehicle-dynamics-3.11.md)解释了每轮载荷/滑移、横摆率、实际转角、力预算、低速运动学侧滑与仍待真人采集的部分。原 30 工况矩阵的逐轮曲线保留载荷、侧偏、纵向滑移、Fx/Fy、摩擦利用率和轮角；逐轮驱动/制动力矩、ABS/TCS 状态由现场连续 capture 另行记录，没有把后者当成原矩阵已有列。全部 120 Hz 步参与统计，20 Hz 原始曲线保留实际输入与状态，飞行曲线另有实际推力；没有强改实际速度/横摆或增加 μ 来压低侧滑数值。前三行的速度、β、横摆和轨迹见[道路数值图（SVG）](../qa/figures/dynamics-3.11-road.svg) / [PNG](../qa/figures/dynamics-3.11-road.png)，该图对应短时协议。

## 3. E/Q、姿态滑条与 X：更快手动，真实保留代价

新会话“标准”默认升降为 5 m/s、升降加速度 5 m/s²、滚转/俯仰参考 180/60°/s、角加速度参考 360°/s²。另有柔和与机动预设，滑条直接设定响应，不使用按住时间越长越快的方式；已有用户偏好与旧实验参数继续保留。

同样目标 8 m/s、按 E 4 s、G 关闭，达到 95% 目标的时间 **2.792 → 1.783 s**，松键额外上升距离 **10.593 → 6.509 m**，仍需要真实制动时间。80 m 恒压条件、无预升高手动完整滚转的松键时刻 **3.400 → 2.250 s**，实际峰值 **154.58 → 202.56°/s**，含恢复最大掉高 **27.011 → 12.341 m**。

X 改为共享所选滚转速率/加速度包络及跟踪方式。标准 X 实际峰值 **187.00°/s**，完整预升高、滚转、返回约 **12.700 s**，最高比起点高 **31.009 m**；机动 X 为 **248.95°/s、9.367 s、+19.903 m**。同一机动设置的手动预升高滚转达到 **251.91°/s**，但手动恢复停在较高位置，没有复制 X 的自动返回轨迹。

同初态、同响应预设的实际姿态、角速度、高度和喷口总实际推力见[飞行数值图（SVG）](../qa/figures/dynamics-3.11-flight.svg) / [PNG](../qa/figures/dynamics-3.11-flight.png)。曲线来自恒压求解器，不包含 WebGL 或 GPU 性能。

标准预设保留较宽的短按回正余量：约 0.7 s 滚转输入后，标准累计 85.40°、回正最大掉高 3.204 m；机动累计 114.33°、掉高 10.664 m。实际新会话默认是 bench 恒压试验台、600 L 参数；城市标准和机动 UI 预设在 free / hover 起点均可完成。另设有限 900 L 时，这两种预设的四个起点组合都被剩余冲量预检拒绝，车辆位置不变；不能把恒压试验台或更高速参考样本的成功说成有限 900 L 已通过。风场实验室约 24.1 m 梁底也不足以容纳标准 X 包络，保留正确拒绝。较慢 X 的额外净空和气耗是真实代价，有限气源可玩范围仍需继续改善。

标准/机动与恒压/有限 900 L 的城市 free/hover 数值对照、拒绝状态及供气结果见 [`qa/flight-capacity-3.11.json`](../qa/flight-capacity-3.11.json)。

5 m 无预升高手动翻转发生了刚性车轮限位撞地：接触前垂速 −7.570 m/s，10 个限位接触、0 个车壳接触，不能算空中恢复成功。此次纠正的是数值辅助测试的接触分类，生产采集此前已有刚体接触检查。G 的水平恢复、航向语义、手动姿态语义和研究定姿定点控制保持区分；3.9 的未密封吸附修复继续保留。

## 4. 条纹、夜景和材质：机制已改，图形验收未结束

最新实图中的机盖/前翼子板密集横带不能作为正常车漆接受。`receiver-plane-shadows.js` 为 PCF 每个实际纹素中心校正接收平面深度，在独立斜面 oracle 的 6400 个采样相位中，无遮挡平均可见度 **0.801532 → 1**，真实遮挡仍为 0。它不增加阴影采样或灯数，也不靠调暗高光藏条纹；但这只验证了一个已确认的错误机制，**尚未证明用户所有条纹均已消失**。

检视页新增完整材质、关闭校正、无接收阴影、无环境反射、灰模、法线、网格七帧 ZIP，采集时冻结相机/LOD/悬架/尾翼并同步复制原始像素，再关联条件 JSON。已有 fixture 证明状态恢复与文件绑定，合成标记字节没有被当作 WebGL 成品图。

夜间的主要新修复是：原 3.10 离线场仅含反射光，远灯退出有限实时灯池后，灯壳仍亮但路面和建筑少了直接受光项。新增静态直接场补上该项，用相机相关权重与实时光互补，保留原相机灯池、滞回、淡变及暂停更新。另修正高度退场被重复相乘的问题：等能量输入在过渡中由 `(1-h)+h²` 改为 `(1-h)+h`；28 m 的代数值 0.75 → 1 不等于实测建筑亮度增加 25%。

新直接场解码数据 3,334,320 B，和原夜反射场合计 6,668,640 B；没有增加实时动态灯，但新增纹理读取有成本。它使用闭合城市包络可见性与有预算插值，微小立面/窄巷仍可能漏光或被软化。混凝土、干沥青、湿膜、积水、玻璃和车漆继续分类；不能只凭旧图“像镜子”反推所有材料 metalness 都设错。

92 对城市/车辆材质 shader 经离线兼容编译通过，后处理为 13 对 exact pass、5 对兼容通过。兼容处理只在临时编译输入重命名 stock Three 的 `average`，生产 vendor 未改；FXAA 为离线 exact pass。**这些不能替代目标 GPU 的 X3595/X4000 日志、像素或运动稳定性检查。** [图形实现、源码位置与同条件采集要求](visual-3.11.md)保留全部限制。

## 5. 城市、车模、研究和首页实际推进范围

原完整城市与路线保留。承接的 3.10 实改包括首层门廊/店面/服务入口、转角与材料层次，以及针对织桥商业街、交换厅高架和南岸连接段的区别设计；车体按当前官方参考保留楔形和硬折线，推进截面、轮拱衔接、玻璃/灯组/轮毂/内饰层次。它们随本次接续进入交付，但**全城远景与边界的完整重设计没有完成**，也没有当前实机后图证明已达到预期画质。

研究实验室落实了 **5 个明确种子 × 2 档延迟 × A/B 控制器，共 20 次、每次 12 s** 的对照。它调用实际研究定姿定点控制器，使 `attitudeResponse` 确实进入力矩请求；普通 G 回正保留独立，避免给一个无效参数换标签就称为 A/B。结果保留失败、误差、掉高、饱和、实际气量/电量和完整请求，导入后重算而不信任导出的汇总。

固定初态、风扰、观测噪声与恒压条件下，A=4.5 / B=2.5 rad/s 的示例结果为：

| 控制器 / 延迟 | 恢复成功 | 高度误差 RMSE 均值 | 实际外部气量均值 | 最长饱和 |
|---|---:|---:|---:|---:|
| A / 0 ms | 5/5 | 0.0224 m | 471.36 kg | 0.258 s |
| B / 0 ms | 5/5 | 0.0478 m | 476.49 kg | 0.483 s |
| A / 120 ms | 0/5 | 19.0666 m | 737.81 kg | 7.842 s |
| B / 120 ms | 5/5 | 0.0565 m | 475.62 kg | 0.475 s |

延迟 A 的失败表现为向上偏离高度目标，不能因最大“掉高”较小而称其安全。这五个种子只揭示该协议下的敏感性，不是总体可靠性估计或最优控制器证明。[完整研究协议](research-robustness-3.11.md)包含噪声、延迟、风、喷口降额和成功窗口。

成功运行后仍显示未运行的状态问题已经在未发布 3.10 以完整请求/尝试身份修正，本轮承接并回归。历史记录、即时保存、旧模型精确重放与当前显式重算继续分离；旧 3.9/3.10 补入等效垂直加速度 3 m/s²，不套用新默认。达到原 4 MiB 存储上限时不删旧记录，新结果可在会话中完整导出。README 中英文已面向潜在用户重写，图片明确标注为真实 3.9 历史画面，没有用概念图冒充当前成品。

### 研究观察窗口与控制器 A/B 的收尾修复

共享约束后的标准 X 包含更长的预升高、旋转、制动与返回过程，原实验固定 8 s 窗口会在真实落地前结束。研究滚转新增 **20 s 标准窗口 / 8 s 历史窗口**，观察时长写入有效请求、`flat-lab-4` 协议和运行身份；界面切换即时保存，导入方案同步显示其真实窗口。旧报告原文不改写，旧草稿、研究包导入/导出及显式重算继续保留 8 s；窗口缺失且无法识别、或请求与报告冲突时拒绝执行。

在相同 bench 600 L、350 bar 和标准响应设置下，8 s 记录包含 160 行，结束高度 9.77699 m，结论仍为“窗口结束但尚未稳定落地”。20 s 记录包含 400 行 / 2400 个物理步，实际首次承载触轮在 **11.88333 s**、接触前垂速 **0.29992 m/s**，持续满足原落地阈值 0.5 s 后于 **12.38333 s** 确认稳定；完整旋转 360°、车壳接触为 0，外部实际供气 **454.82177 kg**，车载耗气为 0。历史读取上限覆盖这 400 行，刷新后不会把曲线截断。更慢的自选参考仍可能超出窗口，有限气源仍可在冲量不足时被预检拒绝。

最终 DOM 回归还定位了一个真实 A/B 失败：界面携带新控制参数 `verticalAccelerationMps2`，但快照回放的本地控制字段白名单遗漏了它，导致合法配对被误判为执行失败。`dist/experiment-records.js` 已补齐该公开控制字段；只改变该字段 5→6 的配对可以执行，轮胎抓地和未知字段继续拒绝。相关修改位于 `dist/research-protocol.js`、`dist/experiment-worker.js`、`dist/research-lab.js`、`dist/research-study.js` 及中英文说明。证据见 [`qa/research-study-3.11.json`](../qa/research-study-3.11.json)、[`qa/research-workflow-3.11.json`](../qa/research-workflow-3.11.json) 与 [`qa/experiment-console-dom-3.11.json`](../qa/experiment-console-dom-3.11.json)。

## 6. 验收状态与继续闭合的工作

[公开载荷清单](publication-payloads-3.11.md)逐项列明原始照明系数与完整数值证据的来源、大小和哈希。用户新上传原始条纹图完整留存在本地，公开版本仅保留其诊断与来源哈希，站点运行不依赖该图。

已完成的是带来源的动力学对照、固定窗口的长期稳态圆弧回归、接触/守恒预算检查、研究复现与历史兼容、阴影/光场数值机制、原始帧绑定逻辑及离线 shader 检查。最终整合门禁由 `npm run validate` 记录到 `dist/validation.json`，任何旧报告或来源哈希不一致的结果都不能转作当前通过证据。

仍开放的项目：

- 实际键盘轻按/转向、松油/带油的连续驾驶手感，以及车头、速度方向和相机跟随的联合检查；固定轮角稳态回归没有代替这些体验验收。
- 当前车体同机位、同分辨率、同画质、同环境的条纹/曲面原图；玻璃和高光层次。
- 夜景暗部、镜面观感、固定相机与车分离时灯池表现、移动中的照明/反射/阴影/抗锯齿稳定性。
- 加载、预热、驾驶与暂停分开的帧时 p50/p95/p99、长帧及可取得的实际 GPU 数据。
- 完整城市边界与远景设计，以及更广的捕获域/最低恢复高度地图和路线/落点/有限气源挑战。

采集从[原网站](https://windscode.github.io/roadster-flight-lab/)、[车辆检视](https://windscode.github.io/roadster-flight-lab/vehicle-inspection.html)和[研究入口](https://windscode.github.io/roadster-flight-lab/?view=lab)继续。当前开发浏览器 GL 被禁用，因此没有把降级研究页当成三维体验完成，也没有删掉图形验收要求。700 kW、干地 μ=1.25、主喷口每个 20 kN 等继续作为项目工程假设，不能表述成 Tesla 实测或原厂 CAD。
