## 城市静帧：严格条件组与新灯光组分开

入口：[当前城市](https://windscode.github.io/roadster-flight-lab/)。打开 **工程面板 → 视景**。

1. 先记录线上 `deployment.json`、页面版本、浏览器、实际 renderer 可用信息。未知 GPU 保持未知。用当前提交源码或部署标识区分版本，不能只依赖缓存页面里的文字。
2. 首先使用 **1280×720 实际 drawing buffer、高画质、相同设备像素比**。视口尺寸和 drawing buffer 都以导出 JSON 为准；不把整个浏览器外框的尺寸当成渲染分辨率。
3. 依次选择 **01 织桥入口、02 交换厅、05 南岸归途**，它们沿用原相机坐标与 48° 垂直 FOV。补 03 高架桥下、04 横街路口及新加的横街/机造大道机位用于衔接检查，后者没有首批旧图对应。
4. 车辆的位置、四元数、车灯、尾翼、飞行/驾驶状态也要相同。固定街景相机不会自动把车辆挪回旧位置。原图缺少完整状态时，应先在原 3.9 checkout 重采匹配基线，再与 3.10 配对；不要猜一个位置后标成严格 A/B。
5. 暂停物理后继续渲染至少 3 s，等待灯池和相机曝光收敛。采用 **3.9 同时段曝光**：晴天 0.87、湿夜 1.02。锁定曝光不会把新版灯具和间接光改回旧版，因此灯光系统变化仍需单独标注。
6. 点击 **保存真实画面 + 同帧条件 ZIP**。它保存直接来自当前 WebGL 帧的 PNG 和本帧冻结的 JSON，包括实际相机、曝光、车辆状态、画质、drawing buffer、灯池 ID/淡入权重、夜间场身份及反射更新时间。独立的“条件 JSON”按钮仍表示点击时的当前状态，不能任意与更早的图片配对。
7. 另采一组默认新灯光呈现，标为“3.10 默认预设”，与上面的受控组分开。2031×1244 的增补分辨率也独立建组。

完整城市没有删除。线路仍为约 **1,135 m** 的织桥—交换厅—中央横街—机造大道—南岸闭环，约 2–3 分钟取决于驾驶与路口减速。静帧不是路线覆盖或驾驶性能证明。

## 车模：一支镜头下同时采两个模型

入口：[车辆曲面检视](https://windscode.github.io/roadster-flight-lab/vehicle-inspection.html)。选择 **3.9 基线**，保留 3.8 作为历史参考。

- 镜头维持 50 mm，转向 0，悬架长度 0.287 m，尾翼 0，剖视与悬架扫查关闭。
- 前灯/鼻部、前四分之三、正侧各采一组；车库条灯与宽自然光分别采，不替换原灯光来掩盖形体。
- 使用同次对照采集 ZIP，保存两个实际渲染帧及关联条件。冻结的 3.9 是原车模/材质代码，在当前渲染器中用同一灯光显示；它不是完整旧版渲染流水线。
- 再补后四分之三、后轮/肩线，以及转向/悬架扫查短片，检查缝隙、玻璃排序和轮胎包络。车辆在城市晴天/湿夜下的近景另采，光棚不能替代街景。

官方照片的镜头、内参和实车尺寸没有完整公开。50 mm 是本项目的重复检视条件，不能宣称重建了 Tesla CAD 或官方摄影机。

## 运动与性能：需要什么数据

城市一轮完整驾驶按相同路线、天气、分辨率与画质采集。性能工具将 **加载、至少 5 s 预热、稳态连续驾驶、暂停截图**分开。报告显示帧时 p50/p95/p99、长帧，附 CPU 提交/物理时间，以及实际 GPU query 可用性。GPU 计时不可用时留空；Node 数值积分速度不能补填 GPU 毫秒。

同次记录驾驶输入与轨迹，尤其检查湿夜通过灯池交接、路面斜视、相机转向时的明暗跳变、细线闪烁、锯齿和反射稳定性。主线程 CPU、GPU 与浏览器调度应分开判断。流畅档没有平面湿路反射，夜场较粗；高档有更多反射与阴影工作，两个档位分别验收。

原日志的 X3595 / X4000 提供了检查线索。本轮 FXAA 本地适配器将单 mip 后处理纹理的边缘搜索采样改为显式 LOD 0，并使用已初始化结果和单一返回路径，处理可确认的控制流/隐式导数风险。依据是 [Khronos GLSL ES 规范](https://registry.khronos.org/OpenGL/specs/es/3.2/GLSL_ES_Specification_3.20.html) 中非均匀控制流的导数约束。离线编译只验证语法与接口；仍需实际 ANGLE/驱动日志确认警告是否消失，运动录像确认是否有可见改善。

## 连续操纵与研究状态回归

**工程面板 → 实验 → 连续操纵采集**提供完整输入、状态曲线与原始统计；[协议、数值结果与后续实验设计](control-capture-3.10.md) 说明具体条件。

54 / 90 km/h 从静止起点真实加速；稳态连续两秒后，持续转向四秒，再制动。E 8 m/s 测松键后爬升距离、稳定时间和 Q 接地阀门收束。Z/B、1/2 后的 G 测恢复时间、掉高、姿态与饱和。人工驾驶随时接管，取消或失败保留记录。

这些工具已经接入同一物理和现场记录器。数值回归不是用户电脑驾驶手感验收；用户原先的 26 / 22 km/h 截图，也不能替代新的稳定速度协议。研究成功运行后的待运行状态残留已修，历史身份、原条件重放与显式当前模型重算继续分开。
