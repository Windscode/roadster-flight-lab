# 1.1 车辆模型审查

本次以 1.0 `88ddb11` 的真实前 3/4 检视图和实际参数曲面为基线。2026-10-25 再次读取 [Tesla Roadster 官方页面](https://www.tesla.com/roadster?redirect=no)，下载并查看官方 `Roadster-08-End-Desktop.jpg`；图片 SHA-256 为 `342e862f7239479b0d1994d1f842e50d05e926b8fd4c9158c02cc9f011bcc71b`，与已有参考记录一致。参考原图仅在本地临时目录查看，未重新打包进仓库或站点。

官方图片支持宽阔的白色前角、闭合的黑色上部鼻面、独立的下部开口和有棱线的机盖这一设计方向。图片没有提供可标定的相机或工程尺寸，本轮没有把像素差解释为真实尺寸，也没有更改轮距、轴距、轮胎、悬架行程、喷口或物理碰撞体。

## 已修复的实际缺陷

- **前折边高差。** 1.0 中央机盖折边落到 `y=-0.026 m`，相邻包角顶点仍保留机盖高度，形成约 **15.90 mm** 的错台。现在两者共用边界，并用真实曲面回卷连接机盖和前脸。
- **前开口漏面。** 黑色开口返回面按较窄的开口宽度开始，未接到白色包角。旧版在左右 `x=±0.635 m, y=-0.140 m` 的前向射线可以穿过外壳；现在返回面连接到实际外壳边界，三档画质均闭合。
- **侧面高光断接。** 原前包角仅与侧皮肤位置对齐，端部纵向切线仍不同。现在匹配侧皮肤的真实斜率，顶部回卷与前面相切；下部碳色包角复用同样的边界。曲面端点的法线计算使用表面内侧差分，避免站点范围外的常数钳制造成斜率减半。

这轮通过重新安排既有曲面完成修复：三档画质的三角形和绘制批次均与 1.0 一致，车漆、玻璃、橡胶和金属的颜色及材质参数不变。没有新增装饰网格，也没有缩小车轮或压缩悬架运动来避免穿模。

## 审查边界

已具备的能力包括独立车身与底部结构、实际轮胎/悬架状态映射、制动灯和方向盘联动、不同材质、可剖视实验设备和单独的照片双座展示。驾驶中的单座实验舱与检视页双座照片研究是明确区分的配置，不把隐藏结构当成原厂资料。轮胎仍为刚性显示几何，悬架连杆为说明性机构；玻璃使用透明层近似，车壳碰撞体也不是逐三角形网格。
