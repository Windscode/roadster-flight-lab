# 3.24 — 连续尾部曲面、可读街景与可重复实验

从本地 3.23 `bb2fd93` 延续。本文件描述本轮源码与实际验收，不代表 GitHub Pages 已更新，也不把四条长期主线视为已经完成。

## 实际变化

**车辆外形。** 后翼子板从侧面连续卷向尾面，补齐上缘、内侧卷边和下部收口；安装凹腔改为连续圆角曲面。保留实验喷口、抽吸风道、灯具、轮位和悬架运动。车漆、碳色结构、金属喷口和轮胎仍用各自材质。剖视保留。绘制批次不增，balanced / high / ultra 三角形分别增加 56 / 16 / 100。视觉后界延长约 9.08 mm，物理硬点未改，粗碰撞体与外饰件仍有近似差异。

这是一项独立造型重建。当前 Tesla 主站已读取，但本轮官方后部原图访问失败；不能把已有实验设备位置当成新核实的原厂结构或精确尺寸。

**城市首层。** 210 个既有浅展示柜加入顶侧细灯条和局限在各自柜内的漫反射照明，让已有背板、货架和商品能被看清。三个有限光源采样是低功率近似，不模拟商品互遮挡、镜面或柜外溢光；玻璃和整扇窗不作为发光屏。建筑的 955 个绘制批次不增，横街另增两个批次；新增实例属性共 889,248 字节。保留全城路网、2368 个共享几何实体、外部光源锚点与原夜间烘焙。通过实际输入身份验证兼容性，未改写旧烘焙 manifest，也未声称柜内新灯已重烘焙。

**翻转预检。** 新分阶段估计积分升力、阀门响应、旋转时的差动力和着陆下降，再叠加有声明的高度、时间和姿态余量。默认工况、10 m/s 下，X 对 10–25 m 的近屋顶仍拒绝，30–45 m 的保留可行场景可完成。原 1.5 s 翻转参考、执行器限制、着陆控制与轮胎抓地未增强。

细包络只在默认物理参数、理想观测、平路四轮起步、收稳执行器和静风恒压供气下启用。自定义参数、观测实验、沿途台阶/缺地等回退旧估计，参数差异和回退原因进入预检数据。独立审查发现的 250 ms 延迟观测碰棚反例已加入拒绝回归。低重力下旧回退仍可能漏检；保留真实碰撞并正确中止的反例，绝不称回退为安全保证。两种估计都不是连续扫掠体规划器，未来输入、薄障碍和横向漂移仍有局限。

**记录恢复。** 实际浏览器发现：同一构建的 Node 数值记录与 Chrome 现场，原始场景哈希不同而无法三维重放。新增有精度声明的可移植几何身份，保留原始身份和旧快照严格路径；刚体顺序、类型和形状布局仍需一致。恢复前在隔离求解器检查完整快照，失败不得先取消当前记录或改变现场。现有完整输入、资源账本、复现误差与返回现场流程继续共用。修正连续操纵协议中遗漏已实现再生制动的过期说明。

## 本机验收结果

2026-10-25 最终构建的 40 项发布门禁（含 DOM）全部通过，另刷新车辆材质与物理研究专项。真实 Chromium / WebGL 按原条件完成 302.5 m、43.708 s、5245 步资源路线重放：876 个已存时刻全部比较，终点位置误差 2.84×10⁻¹⁴ m，复现判定通过，容差未放宽。返回后完整物理快照逐字一致，天气、曝光、画质和固定机位投影一致；固定模式未使用的 orbitTarget 被规范为当前 look-at，不能称所有相机内部字段逐字一致。

湿夜高画质、1280×720、RTX 4080 SUPER 的 5 s 预热 + 30 s 活动采样共 3217 帧，帧时间 p50 / p95 / p99 为 6.1 / 18.1 / 18.3 ms，GPU p95 为 11.88 ms。仍记录到一次 697 ms 长帧，反射 CPU 阶段占 690.6 ms；原因尚未证明，应优先复查首次反射路径与编译。采样期间同机有两项短数值/材质回归，因此不将该样本当成独占硬件基准，也不声称完整 150 s 城市环线已验收。

新记录在 Node 与浏览器的原始哈希分别为 716ddeea / e2f09b9c，可移植几何身份均为 aa20fe4e。旧记录不补造身份。三维重放与同初态练习共用校验；跨引擎新尝试的保存结果比较仍按原始内容标签保守判定，尚未把来源标签与语义等价完全拆开。

## 仍需推进

继续从整车轮廓、前后体量、玻璃与座舱关系改善模型；城市需要更丰富的分区材料、店铺功能与街道生活，而不是只增加灯。性能需逐步扩大到完整 150 s 环线、多画质和多设备。研究侧下一步应验证有限气源下的动作可行域、跨运行环境的长期复现容差与更多控制器对照。当前缓存场景的完整销毁生命周期仍不完善，实施城市热重载前必须补齐。
