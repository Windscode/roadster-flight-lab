# Roadster Flight Lab · 1.0

**从街道开到空中，把一次驾驶变成可以解释和重放的实验。**

[进入城市](https://windscode.github.io/roadster-flight-lab/) · [风场实验室](https://windscode.github.io/roadster-flight-lab/?view=lab) · [车辆检视](https://windscode.github.io/roadster-flight-lab/vehicle-inspection.html) · [English](README.en.md)

个人探索、中等规模的车辆驾驶、冷气喷射飞行与自动控制研究。车辆动力学、车辆模型、连续城市和研究玩法长期共同发展。物理参数与未公开的车辆结构属于明确的工程假设，不是 Tesla 的精确工程模型；赛博朋克式城市是视觉方向，不以牺牲流畅度换规模。

## 1.0 正式版本

基于完整 3.24 成果推出首个产品版本；此前 3.x 为开发迭代编号。新增可靠的非默认翻转筛查、完整初态比较和 3.24 记录显式重算，改善前车身曲面、夜间灯光编译与反射准备，并让路线挑战及改键提示更容易使用。完整城市和现有研究玩法保留。

## 继承的 3.24 车身、街景与可重复实验

- **尾部形体**：后翼子板连续包裹到尾部，增加真实卷边与凹腔收口。原实验喷口、抽吸风道、轮位和剖视保留；不是原厂 CAD。车辆绘制批次不增加。
- **街边橱窗**：210 个既有展示柜增加局限在柜内的低功率照明近似，让货架与陈列在晴天和湿夜都可辨认。完整城市、道路碰撞和外部灯光预算保留；没有把整扇窗做成发光屏。
- **翻转净空**：默认物理、理想观测、平路和收稳执行器下，按动作阶段预测车体上界，减少已经落地后才遇桥的误拒绝。自定义参数、有限气源、风场、故障及观测延迟回退原保守估计；两种方法都不是连续碰撞保证。
- **研究与复盘**：新增有精度声明的可移植场景身份，处理 Node / 浏览器几何生成的浮点末位差；真实几何或刚体结构不匹配仍拒绝，恢复先验证后改变现场。旧记录保留原严格规则。

## 继承的 3.23 改进

- **自动动作与碰撞**：X/U 共同检查预计滑行路径的上方净空；车壳碰撞后标记动作未完成，继续用实际执行器尝试回稳。保留 X 原有 1.5 秒翻转参考，不增加推力或抓地力。净空预检是保守采样估计，可能拒绝实际可完成的近桥动作。
- **活动部件阴影**：尾翼、转向、悬架、裙边及车辆显示细节变化同步刷新实际投影；隐藏或不投影的部件不增加刷新次数。
- **驾驶成果保存**：无法读取的旧资源摘要受到保护；存储失败时保留本会话所有结果，驾驶结束立即提示未保存，并可导出原文、摘要与保存状态。
- **本地开发可靠性**：保留完整 3.21/3.22 Git 历史，防止 Windows 换行转换破坏构建与历史证据哈希。菜单版本随实际源码更新，修正过期的回充说明。

## 继承的 3.22 改进

- **输入可靠性**：关闭菜单或编辑框后，持续按住的手柄油门/升降必须回中才重新生效；Ctrl/Meta/Alt 浏览器快捷键不再误触发车辆指令。
- **夜间光影**：修复切换画质时重复分配路灯，以及关灯移动后停车开灯仍使用旧阴影相机；保留动态阴影与原光源预算。
- **车辆状态表现**：座舱方向盘跟随实际转角；切换灯光模式不会熄灭正在制动的尾灯。方向盘比例属于展示假设，并非 Tesla 工程数据。
- **实验与能量**：复盘分别显示净用电、供电与回充；复位不会被记作回充。反向驱动产生的制动热有独立账目，零负压附着不会令仿真出现非有限状态。

## 继承的 3.21 功能

- **再生制动**：按车轮实际被制动的机械功计算回充，受充电功率、SOC、效率与剩余容量限制；回充不可用时由摩擦制动补足原制动需求。电池收支、制动热、滚动阻力与轮胎滑移分别记账。
- **统一输入**：菜单或帮助中打开“输入与手柄设置”。支持改键、手柄映射和分步校准。首次连接、失焦、暂停、改绑与断连后清除旧指令并要求释放输入；键盘、触屏及手柄共用动作语义。
- **有限资源路线**：暂停后打开地图，准备织桥街路线，选择有限资源或自由练习，然后“开始驾驶并记录”。挑战长 302.5 米、65 秒，初始可用电量 120 Wh；这是 200 kWh 电池近耗尽的情景，不是实际 Roadster 续航预测。
- **比较与复盘**：最近六次资源摘要可导出。仅相同构建、路线、参数和完整初态的成功记录显示成绩差值；失败仍保留。完整输入重放从原实验记录进入，原有现场与研究记录相互独立。
- **可靠性**：修复物理保护触发后的账本/快照崩溃、不同记录被误结束、路线准备状态失效，以及全新 Git 检出无法直接启动等问题。

## 本地开发

Node.js 22 或更新版本；运行依赖已随仓库保存，无需安装生产依赖。

```bash
npm start
# 编辑 dist/ 中的源码，刷新页面
npm run model:build
npm run test:release
```

`ROADSTER_PORT=8090 npm start` 可指定端口。浏览器应使用 HTTP，不使用 `file://`。完整发布检查先用 `npm ci --prefix tests/dom --ignore-scripts` 安装锁定的测试依赖，再将 `JSDOM_MODULE_PATH` 设为 `tests/dom/node_modules/jsdom/lib/api.js` 的绝对路径；没有时报告会明确标为未执行。历史 `npm run validate` 包含早期完整归档依赖，不能替代本轮具名验证，也不能把缺失历史资料误报为当前代码失败。

发布沿用原 GitHub Pages workflow。当前运行源码在 `dist/`，`physics-kernel-319.js` 延续已发布 3.19 的接触与飞行控制实现，并包含已说明的边界修复，`physics.js` 集成资源账本，`resource-wheels.js` 处理实际轮功与制动混合。新的源码构建身份覆盖所有运行 JS/HTML/CSS。详见 [开发说明](docs/DEVELOPMENT.md)。

## 验证边界

3.23 的历史验收包含实际求解器、完整快照重放、DOM 事件和本地 HTTP/发布身份检查。该轮连续测试没有复现历史的 X 落地长时间前翘、G 旧位置拉回、G 关闭时驾驶模式无输入喷气；W+E+1 在测试中同时到达求解器。这不代表所有初态或真实键盘硬件已经覆盖。

3.23 曾在本机浏览器运行真实 WebGL，并检查驾驶、X 落地、组合输入、晴天/湿夜与画质切换。浏览器自动化不等同于物理键盘、手柄和音频听感验收；该轮也未证明所有运动阴影闪烁均已消除。3.23 没有扩建城市或新增美术资产。1.0 的当前验收与限制见[本轮说明](docs/release-1.0.md)。旧版本报告和图片保留原身份：[3.16 历史 README](docs/history/README-3.16-candidate.md)、[3.19 恢复范围](docs/recovery-release-3.19.md)。3.21 的旧实验可查看/导出，但暂不提供跨版本精确重放或自动迁移；新模型应重新录制。
