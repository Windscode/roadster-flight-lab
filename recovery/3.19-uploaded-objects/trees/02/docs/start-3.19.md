# Roadster Flight Lab 3.19：开始体验

这是从完整 3.18 继续开发的私人本地候选。完整城市、车模、研究台和历史记录功能仍在；本轮没有发布 GitHub 或网站。当前构建身份以包内 `dist/deployment.json`、`CANDIDATE_FILES.json` 及同轮 VERIFY 为准。

## 启动

1. 将整个候选 ZIP 解压到一个新的空文件夹，勿混入旧版本文件。
2. 已有 Python 3 时，Windows 双击 `START_WINDOWS.cmd`；macOS / Linux 执行 `sh START_MAC_LINUX.sh`。也可执行 `python3 launch.py`。
3. 启动器先验证所有文件与模型身份，再监听本机 `127.0.0.1:8320` 并打开浏览器。不需要 npm 安装，也不向外公开服务。
4. 端口被占用时，按提示使用另一端口，例如 `python3 launch.py --port 8321`；启动器不会结束已有服务。

单独检查包：`python3 launch.py --check-only`。若报缺文件或身份不符，重新完整解压；不要用旧远端文件覆盖。

三维驾驶需要可用的 WebGL 2。当前交付环境的浏览器报告 `GL_VENDOR = Disabled / GL_RENDERER = Disabled`；本轮三维实机验收尚未完成。图形不可用时，已有记录查看、导出和标准数值研究仍保留。

## A：一段连续城市路况体验

按 **M**，或打开菜单的“城市路线 / 驾飞练习”。在“一段路，读懂车的反应”中选择“干燥白天”“雨后白天”或“雨后夜间”，暂停后点击“准备路线 · 复位并暂停”，再点“开始驾驶并记录”。

准备会把当前车辆置于这次路线起点并建立新记录条件，清除旧输入。车辆参数和风场沿用当前设置并随完整初态记录。驾驶期间切换观赏昼夜不改变抓地；只有明确重新准备才应用另一组路面。

这条路线使用已有道路，标称长 **302.5 m**：沿织桥街直行，在 247.5 m 附近 **A 左转**进入横街，再于终点停车。建议直路约 30 km/h、入弯前减到约 15 km/h。黄金路线显示在地图和小地图；实际驾驶会在路口走弧线，因此累计车程与折线长度不同。

| 操作 | 用途 |
|---|---|
| W / S | 驱动、减速及倒车；沿用既有换向逻辑 |
| A / D | 左右转向 |
| 空格 | 制动 |
| C | 切换机位，含驾驶舱 |
| P / Esc | 暂停与菜单 |
| M | 路线及驾飞练习 |

桥下金属跨越面、局部潮湿带、修补面和半幅干湿交界使用同一份可序列化描述供材质与各轮实际接触查询。湿润、光学反射和附着是不同字段；这是有限工程近似，没有水膜流体或水滑求解。平的纹理不会产生假台阶。

路线卡显示四轮当前表面与 μ、ABS 和滑移耗散。勾选声音后，轮胎摩擦、制动调制和轻重落地来自实际轮载/滑移功率及接触开始事件；默认不强制播放。驾驶舱轻微头部惯性可以关闭，只移动眼点，不改变车体或固定研究机位。

顺序经过全部路段、在终点四轮低速停稳半秒后，记录自动结束。可点“查看这次记录 / 原条件重放”，直接选中这次记录。手动结束或在其他面板停止会保留实际结束原因。每次再次尝试都需要重新准备，不能在终点重复生成“走完全程”的结果。

工程面板仍提供旧 dry / wet / split。启用路线图时，下方会明确说明下拉框只是区域外后备工况；更改会退出路线图。研究可继续分别调整光学与物理条件。

## B：失败后看过程，再练习一次

地图中保留已有上城驾飞挑战。首次不想把活车开回起点时，选“独立练习起点”，再点浮卡“开始这次练习”。“独立练习起点”入口使用恒压外供气；从已有记录准备练习则保留该记录原供气条件。原现场车辆与资源暂存并暂停，练习不计正式排名。

1. **读结果。** 失败卡显示第一条违规、实际量、阈值和此前事件。例如触地前下降速度 7.94 m/s 超过 1.4 m/s，而不是只显示“硬着陆”。
2. **看过程。** 点“查看这次过程”进入事件前三秒的隔离暂停复盘。使用关键事件按钮或步号查看姿态、轮接触、速度方向、控制来源/目标、请求与实际喷口，并同步曲线游标。
3. **再试一次。** 点“同初态练习一次”，再点“开始这次练习”。风场、气量、温度、参数、控制记忆和判据来自原完整快照；新尝试有新 runId，并链接 parentRunId。
4. **比较实际变化。** 练习结束后按 M 打开地图面板，保留本次记录，在“与哪次尝试比较”中选择来源尝试（子练习默认选中父记录），再点“按事件对齐比较”。起飞、穿门、触地等事件逐项对照，缺失事件保持缺失；不同人手输入不标为严格控制器 A/B。
5. **返回现场。** 从隔离复盘或练习点“返回原现场”，恢复原车的完整状态、资源、机位和导航并保持暂停。活动记录或研究尚未结束时，先结束它们再进入隔离流程。若只打开了不可执行的历史样本卡，关闭卡片保留现场原状态，不额外改变暂停状态。

此复盘入口只有在当前运行的模型版本、构建 ID 与记录一致，且初态检查通过时，才开放三维重放与同初态练习；本页不会自动加载旧 bundle 的模型。旧模型不可用时仅显示保留样本，标明只读/无插值，不偷偷换新版模型重算。研究台原有的显式当前构建复算资格仍由独立合同检查，复算不等于原构建精确复现。

## 本轮验收范围

真实求解的干/湿制动、转弯、跨界、停车、轻重落地、完整路线，以及硬着陆/包络超限/成功三类记录的复盘—练习—比较已由数值与 DOM 集成验证。具体身份与报告见 `docs/acceptance-3.19.md` 和包内小证据。

原生三维连续驾驶、真实扬声器听感、用户 GPU 帧时/显存、日夜最终像素、转角背面与高刷新运动阴影仍需本机验证。不要把这些数值结论当作真实车辆预测；质量、轮胎、气源和推进模型仍为研究假设。

手动 E+1 仍有倒置失败；它与自动 U 不同。90 km/h 严重台阶仍有数值不收敛边界。低供气失败仍保留，不通过放宽判据消除。
