## 1. 驾驶：新增可玩的受控动作，保留真实手动边界

用户原请求的真实顺序是先保持 W，再追加 E 和 1。3.17 在浏览器实验室平地（`?view=lab`）、G 开启的条件下，用实际键盘事件执行了这个顺序；780 个物理步（6.5 s 模拟时长）收到三键，仍没有完成地面后翻，G 回平也受限。数值专项另外覆盖 G 开、关两组，两组均失败；原生手动样本只测了 G 开。输入没有丢失并不等于动作成功。完整原生请求及截图在 [input-native-3.17/first](../qa/input-native-3.17/first/report.json)。该报告保持采集时的 build，不回填最终身份；相同物理/输入源码范围由 [证据归属说明](evidence-scope-3.17.md) 核对。

手动 60°/s 参考一周需要约 6.083 s，较大的俯仰惯量与单向主喷口意味着倒置时无法同时支撑。单轴最大力矩也不能与最大升力同时取得。固定无风、350 bar 外供的完整输入协议只在约 70.78–71.02 m 放置初态高度之间取得一次失败/成功的采样夹逼；这不是普适安全高度，报告不把 120 m 高空成功当作地面问题解决。

新增 **U** 是单独的受控动作：真实起跳、加减速俯仰轨迹、喷口分配、阀门动态、重力和刚体积分、着陆回控。它不修改喷口额定推力、不瞬改姿态、不加隐形支撑，也不锁动画。实际浏览器在实验室平地先保持 W 再追加 U，动作在约 **4.675 s 模拟时长**后四轮回到 DRIVE，CG 峰值约 **6.133 m**，W 保留。该样本不构成完整城市路线中后翻动作的原生验收。默认 350 bar 有限储气冲量预算不足时明确拒绝；已通过的动作使用恒压外供。

原 X 的动作模拟时长仍约 **3.6917 s**，累计滚转 **361.1796°**、CG 峰值 **3.89874 m**，与冻结 3.16 的同工况结果一致。上述动作时间按求解器推进计算；本轮 SwiftShader 浏览器的墙钟耗时明显更长，不能把这些秒数直接当作用户设备的实时体验。详细力矩/惯量/可达集合、喷口请求与实际残差、手动边界、失败原始轨迹见 [车辆操控专项](physics-controls-3.17.md)。

## 2. 接触：修了真实量纲缺陷，严重台阶仍不过关

原接触摩擦把以 N 估算的摩擦力直接作为 N·s 的求解冲量上限，且多个接触点各拿一份整车重力预算。现以同一点真实法向冲量约束两个切向冲量的合成长度。独立滑块解析算例跨质量、频率和运动方向验证了修复。

正常制动、转向与 20 km/h 过 2 cm 缝的逐步刚体轨迹没有退化。但 90 km/h、10 cm 严重台阶在 480/960/1920 Hz 下仍不收敛：修后全宽 960→1920 Hz 末位置差约 2.286 m、末速度差约 1.680 m/s。百万牛级法向峰值仍存在。以全宽 960 Hz 样本为例，首处真实硬接触定位到前轮限位与台阶边缘，后续最大峰值来自前鼻壳；没有把全部异常归咎于显示器上的轮胎支撑数值。

接触功与求解器速度跳变动能相合，只证明约束步骤记账闭合，不证明整个刚性接触模型已物理可信。数值试验过而未可靠解决问题的松弛映射、dt 摩擦近似及冠形轮限位候选都保留在开发失败证据中。

当前城市的一次连续 **190.4 s / 954.603 m** 路线无复位或瞬移。71 个控制步出现刚体阳性，313 个法向方程全部来自前轮限位，车壳方程为零。这是当前城市、原连续驾驶输入程序的新实际求解实验；新增实体导致几何身份不同，旧快照精确重执行被正确拒绝，没有给旧城市记录换身份。

## 3. 车模：主形体和阴影接线分开处理

实际看过用户前侧、座舱、研究观察像素，以及 Tesla 官方可见照片后，保留照片中确实存在的黑色上鼻面和下开口，但收敛其比例并重建横向/纵向曲率、白色鼻角和回边。肩部直接用连续曲面连接顶面与门侧，不用装饰条假装曲率；门面、轮拱回边随同一曲面连接。

真实顶/侧边界的法线夹角由约 76.7–83.5° 降到 0.33–0.81°。车模 drawable 数未增加，极高档只增加约 138 个三角形。左舵眼点、座舱、轮胎包络、尾部真实喷口与安装肋保留；质量、惯量和喷口参数不受视觉文件改变。

研究图上的机盖斜条纹并非靠关阴影消失：中央机盖几何/法线和材质保持相同，找到的是实验室创建车模时漏接既有接收面阴影修正。修正进入公共工厂，仍投影/收影。五组工坊图的机位、灯态和曝光逐项匹配；实验室观察图存在 26.934 mm 的暂停高度差，明确只作定性支持。原图与可见/推测边界见 [车模专项](vehicle-form-3.17.md)。

工坊图采于开发阶段，原 JSON 保留当时尚未重生成的 `28e9…` build 标签；车辆、工坊和阴影等七项实际源码哈希与最终相同，所以它们证明相应形体/阴影改动，不是最终全产品 build 重新拍摄。五组各四份状态记录的 22 项比较条件均一致。普通城市跟随图是暂停画面，用于观察尾部安装和正常跟随外观，不作为持续驾驶测试。

## 4. 城市：保持原城，以街缘和普通立面改善连续体验

Crosstown 原大片前场补为低层连续街缘，沿原道路组织入口、雨棚、退入开口与沿街标识。普通街区的窗墙比例、竖向模块和材质尺度也有调整，改进并不限于一个拍照点。保留原 114 个主建筑地块及道路体系；新增街缘实体和灯座移动有明确碰撞合同，不把穿行道路悄悄变窄。

夜间采用真实灯源的间距与方向交叠、沿街表面间接层次来缩短黑间隔，未统一抬曝光。另修正 CSM 构造器把强度 0 当缺省值替换成 3 的缺陷：旧版夜间切高/极高会出现有强度的太阳，候选保持夜间太阳强度为零，并减少无意义的级联重建。374 门灯自遮挡、湿路反馈循环及 PNG 等待调度修复继续保留。

城市艺术提升并非所有成本都降低：更有区分的模块可能增加某些批次。本轮整轮回归第一轮实际发现植物园视点超过历史 draw 上限，原失败日志保留；后续修复和最终预算见城市专项及最终回归日志，不通过放宽该上限来掩盖。

实际软件渲染器持续观测、切档响应、HTTP 错误和负载差异见 [城市专项](CITY_3.17_REPORT.md)。上层夜景、远景细节和大玻璃店面仍需后续艺术迭代。已能看见实质变化，尚不是 3A 视觉验收。

日间和第一组湿夜候选原图、持续时序采于 `df685…`；性能基线采集还与 CPU 回归重叠，不能据此宣称因果提速。最终 `26692…` 的合批已通过 173,926 个实例等价和未放宽的历史视图预算，并补有一张实际 HTTP 源码身份匹配的湿夜原图，但没有重复最终合批后的持续时序。城市对照保持固定机位、同天气档和曝光；实际光源与环境层次本身是本轮改变对象，不能称其“同一光照场”。

## 5. 研究：读得懂的取舍，而非自动宣布冠军

新规定风对照使用已有高度任务、结果库与实时求解器。默认 strong / seed 31701、350 bar 恒压外供下，B 将固定 2–6 s 高度 RMSE 从约 0.150 m 降至 0.029 m，同窗外供气量增加约 0.793 kg；因更早落稳，全任务气量反而少约 25.48 kg。界面把这些不同口径并列，不以任务时间不同的总量冒充同窗效率。

无风对照显示主要高度差来自起飞收敛；水平误差两组几乎相同。界面声明只改高度外环，失败、不同风序列、窗口不足、取消都不评冠军。独立审查还修复了部分窗口被标成完整窗口、Worker 失败请求缺少实际风计划两项问题。详见 [风扰实验说明](research-wind-3.17.md)。

原生覆盖分阶段记录：`7c77…` 实测完整 Worker、保存、一次下载、重载、三维重执行和观察取消；该草稿未留完整源清单，不能把后修版本全部追认为通过。`df685…` 实测修复后的正常完整窗口 Worker 与保存，并留存完整源哈希。最终 `26692…` 实测导入这三条原生 Worker 归档、保持原记录及完成状态条不遮挡标题/种子；这一步没有重新运行 Worker、重下载或取消。最终与 `df685…` 的研究求解器、统计、Worker 相同，UI 只增加 busy 状态属性，CSS 调整空闲状态条。部分窗口取消和故意 Worker 错误仍由实际求解器记录及隔离 DOM 测试支撑，未做最终原生异常流程。完整映射见 [证据归属说明](evidence-scope-3.17.md)。

## 6. 导出、真实性和回归范围

本轮一次有界的任务库下载真实落盘，与三个完整保存记录一致。其应用编码/交接、浏览器下载事件和工具保存各有独立计时；没有复现用户此前 1758 s 或 2561 s 的浏览器工具挂起，不能据此认定已修复该问题，也不宣传相较 3.15/3.16 全面提速。既有取消、错误反馈和保存记录继续验证。

全部本轮原生渲染采用 Chrome / WebGL2 / SwiftShader。真实像素证明此软件渲染路径能显示实际模型和场景；不能证明用户显卡逐 draw、持续帧率或切档响应已通过。数值求解器、DOM/Worker 错误路径、离线 GLSL、原生浏览器和用户设备是不同证据层级。

`qa/native-acceptance-3.17.json` 的总状态是 `partial-native-acceptance-with-open-gates`。其中最终 build 原生画面、相同相关源码继承的早期观测、明确失败和未测项分开记录，不代表全体验通过；受控动作的静态末态图也不能独自证明完整转角或时间，这些结论来自输入/四元数日志。

最终整轮回归使用 `scripts/validate.mjs`，包含原项目门禁、新俯仰/接触/车模/城市/风扰测试、独立静态可达性计算、DOM 和离线 GLSL。通过的是每条明确合同；报告仍保留手动地面失败、严重台阶失败和未测用户 GPU。测试明细以 `dist/validation.json` 和 `qa/full-regression-3.17/` 为准。
